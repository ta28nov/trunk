# FULL WEBSITE DESIGN & IMPLEMENTATION SPECIFICATION

Create a complete premium website for a truck transportation / logistics company.

Use the Mandatory Design Rules as absolute constraints.

The website should reconstruct the DESIGN PRINCIPLES of award-winning transportation websites such as LODISNA Transport & Logistics, DAMU LOGISTICS and Aden Logistics, while creating a completely original brand experience.

Do NOT copy their exact website.

# 10. TYPOGRAPHY SYSTEM

Use:

Heading:
Satoshi / General Sans / similar

Body:
Inter / similar

Large editorial headings.

Recommended desktop scale:

H1:
80–120px

H2:
48–72px

Body:
16–18px

Small metadata:
12–14px

Responsive typography must scale appropriately.

Do not blindly preserve desktop sizes on mobile.

---

# 11. GRID SYSTEM

Use a consistent grid.

Desktop:

12-column grid.

Use large margins.

Maintain consistent:

* Horizontal padding
* Section spacing
* Alignment
* Image ratios
* Typography rhythm

Do not randomly position elements.

---

# 12. IMAGE SYSTEM

Use consistent aspect ratios.

Hero:

16:9 / cinematic

Service:

4:3 or 16:9

Fleet:

4:3 / portrait where appropriate

Editorial:

Variable ratio where composition requires it.

Images must be optimized.

Use:

WebP
AVIF

where supported.

---

# 13. VIDEO SYSTEM

Use HTML5 video.

Required:

autoplay
muted
loop
playsInline

Provide poster image.

Use responsive sources when necessary.

Do not autoplay audio.

Respect:

prefers-reduced-motion

On mobile, use lighter video or static image when necessary.

---

Use GSAP + ScrollTrigger where appropriate.

Animation categories:

PAGE LOAD

* Hero visual

SCROLL

* Text reveal
* Image reveal
* Section transitions
* Parallax

SERVICE

* Image transitions
* Hover
* Text movement

ROUTE

* Route drawing
* Location reveal
* Truck movement

FLEET

* Image transition
* Specification reveal

CTA

* Background movement
* Typography reveal

Do not create unnecessary animation.

---

# 15. SMOOTH SCROLL

Lenis may be used.

If used:

* Do not break native scrolling.
* Do not create excessive inertia.
* Disable or reduce effects on low-power devices if necessary.
* Ensure accessibility.

---

Navigation:

MENU

Services:

Vertical editorial sections.

Fleet:

Horizontal or vertical slider.

Coverage:

Animations:

Reduced complexity.

# 17. PERFORMANCE REQUIREMENTS

Target:

Fast initial render
Optimized images
Lazy-loaded media
Minimal blocking JavaScript
Responsive video
Code splitting

Do not load:

* Huge videos
* Huge images
* Heavy libraries
* WebGL

until they are actually needed.

# 18. ACCESSIBILITY REQUIREMENTS

Implement:

Semantic HTML

Keyboard navigation
Visible focus states
Alt text

Every page must have:

* Unique title
* Meta description

* Clients
* Certifications
* Delivery statistics
* Routes
* Years of experience
