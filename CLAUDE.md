# MANDATORY DESIGN RULES

## Award-Winning Transportation / Logistics Website

You are designing a premium, modern website for a truck transportation / logistics company.

The design direction must be based on the documented design principles found in award-winning transportation and logistics websites such as LODISNA Transport & Logistics, DAMU LOGISTICS, and Aden Logistics, combined with the visual discipline of high-quality minimalist and editorial e-commerce websites.

IMPORTANT:
Do NOT copy proprietary assets, logos, text, branding, exact layouts, or exact animations from any reference website.

Reconstruct the underlying design principles and create an original visual identity.

---

# 01. CORE DESIGN DIRECTION

The website MUST follow this design language:

* Minimal
* Industrial
* Premium
* Editorial
* Modern transportation
* Strong typography
* Large-scale imagery
* Cinematic video
* Purposeful motion
* High visual hierarchy
* Generous whitespace
* Strong commercial/service presentation

The final result must feel like:

"An award-winning digital showroom for a transportation company."

It must NOT feel like:

* A generic logistics template
* A traditional corporate website
* A dashboard
* A SaaS landing page
* A template filled with cards
* A website overloaded with gradients
* A website where animation exists only for decoration

---

# 02. BUSINESS-FIRST RULE

Every visual decision MUST support the transportation business.

The design hierarchy must follow:

BUSINESS
↓
CONTENT
↓
VISUAL
↓
MOTION
↓
CONVERSION

Never reverse this order.

Do NOT add animation, 3D, gradients, effects, or interactions simply because they look impressive.

Every major visual element must answer at least one question:

* What does this company transport?
* How does the transportation service work?
* Where does it operate?
* What vehicles are available?
* Why should customers trust the company?
* How can customers request the service?

---

# 03. SERVICE-FIRST RULE

The website's primary purpose is to present transportation services.

Services MUST NOT be hidden inside small cards.

Services should be presented as major visual experiences.

Preferred pattern:

SERVICE
↓
DESCRIPTION
↓
VISUAL
↓
CAPABILITY
↓
CTA

Each important service should have enough visual space to communicate what it actually does.

---

# 04. VISUAL HIERARCHY

The user must immediately understand:

WHO
↓
WHAT
↓
WHERE
↓
HOW
↓
CONTACT

Within the first screen, the user should understand:

* Company/business category
* Truck transportation service
* Main value proposition
* Primary CTA

Do NOT make users scroll through multiple sections before understanding what the company does.

---

# 05. COLOR SYSTEM

Use a restrained color system.

Preferred base:

Dark / Black
#0B0B0B

Off-white
#F2F0EA

White
#FFFFFF

Use ONE accent color only.

Possible accent directions:

Lime:
#D7FF3F

OR

Orange:
#FF6A00

Never use both.

The accent color should be reserved for:

* Primary CTA
* Important numbers
* Active states
* Route graphics
* Hover states
* Small visual highlights
* Key interaction points

Do NOT turn the accent color into a dominant background color.

Avoid generic:

* Blue header
* Blue button
* Blue card
* Blue icon
* Blue section
* Blue gradient
* Blue footer

unless the actual brand identity requires it.

---

# 06. TYPOGRAPHY

Typography must be a major part of the visual identity.

Use a maximum of TWO font families.

Preferred direction:

Heading:
Satoshi / General Sans / similar modern grotesk

Body:
Inter / similar neutral sans-serif

Using one font family for the entire site is also acceptable.

Heading rules:

* Large
* Bold
* Strong hierarchy
* Tight composition
* Editorial appearance

Example direction:

MOVING
WHAT
MATTERS.

Avoid:

* Too many font styles
* Decorative fonts
* Excessive uppercase everywhere
* Tiny headings
* Poor line-height
* Excessive text density

Typography must create visual hierarchy before decorative graphics are introduced.

---

# 07. WHITESPACE

Whitespace is mandatory.

Do NOT attempt to fill every empty area.

Use whitespace to:

* Separate content
* Emphasize typography
* Create premium feeling
* Focus attention on truck imagery
* Improve readability
* Create visual rhythm

The website should breathe.

---

# 08. IMAGE RULES

Truck imagery is one of the primary visual assets.

Do NOT use random stock images.

The image direction must be consistent.

Choose ONE visual art direction:

Option A:
Dark industrial / cinematic photography

OR

Option B:
Clean commercial transportation photography

Do not mix completely different photography styles.

Recommended subjects:

* Trucks
* Fleet
* Highway
* Cargo
* Loading
* Warehouse
* Drivers
* Transportation operation
* Delivery
* Route

Images should communicate the actual business.

---

# 09. VIDEO RULES

Video must communicate movement or transportation.

Preferred video locations:

* Hero
* Service sections
* Fleet
* Process
* Final CTA

Video should generally be short and loopable.

Recommended:

Hero:
5–10 seconds

Service:
3–6 seconds

Fleet:
3–5 seconds

CTA:
5–8 seconds

Avoid long corporate introduction videos as the primary visual.

Video must not significantly damage page performance.

Use:

* Lazy loading
* Poster images
* Appropriate compression
* Responsive video sources
* Mobile fallback when necessary

---

# 10. ANIMATION RULE

Animation MUST have purpose.

Use animation to:

* Explain transportation
* Guide attention
* Reveal information
* Demonstrate routes
* Show movement
* Improve hierarchy
* Create continuity between sections

Do NOT animate everything.

Preferred priority:

Hero:
★★★★★

Services:
★★★★★

Route:
★★★★★

Fleet:
★★★★☆

Process:
★★★★☆

About:
★★☆☆☆

Footer:
★☆☆☆☆

---

# 11. LOGISTICS MOTION LANGUAGE

The website should have its own transportation-oriented motion language.

Preferred visual concepts:

Truck
→
Route
→
Destination

Cargo
→
Loading
→
Transportation
→
Delivery

Route lines should be able to:

* Draw progressively
* Connect locations
* Trigger on scroll
* Interact with truck movement

A truck may move along a route.

This is preferred over random:

* Floating shapes
* Random particles
* Decorative blobs
* Excessive 3D effects

---

# 12. MICROINTERACTIONS

Use subtle interactions:

* Button hover
* Image hover
* Navigation hover
* Service hover
* Cursor interaction
* Image reveal
* Text reveal
* Arrow movement

Microinteractions must remain fast and subtle.

Never sacrifice usability for visual effects.

---

# 13. SERVICE PRESENTATION

Do NOT use a generic:

[Service Card]
[Service Card]
[Service Card]
[Service Card]

Instead, use large editorial service sections.

Example:

01

FULL TRUCKLOAD

Dedicated transportation
for high-volume cargo.

[BIG VISUAL]

EXPLORE →

Each major service should feel like a product.

Think:

E-commerce product presentation

but applied to transportation services.

---

# 14. FLEET PRESENTATION

Fleet must be treated as a visual showcase.

For each actual vehicle type, provide where available:

* Vehicle name
* Vehicle image
* Payload
* Capacity
* Cargo suitability
* Relevant specifications

Do NOT invent specifications.

If actual company data is unavailable, use placeholders only during development and clearly mark them as content that must be replaced.

---

# 15. ROUTE / COVERAGE

Coverage should be visual.

Preferred:

Location
↓
Route
↓
Destination

Use:

* Route line
* Map
* Location markers
* Numbers
* Truck movement

Do not create fake coverage statistics.

Only display actual routes, cities, regions, or countries supported by the business.

---

# 16. TRUST

Trust should be communicated through real evidence.

Possible content:

* Years of operation
* Fleet size
* Deliveries
* Coverage
* Certifications
* Clients
* Partners
* Operational capability

All numerical claims MUST be based on actual company information.

Never invent:

* Clients
* Reviews
* Certifications
* Fleet numbers
* Delivery numbers
* Years of experience

---

# 17. CTA

The primary CTA must always be obvious.

Preferred:

REQUEST A QUOTE

Other possible CTA:

GET IN TOUCH
CONTACT US
BOOK TRANSPORTATION

CTA must be accessible from:

* Navigation
* Hero
* Service section where appropriate
* Final CTA

The final CTA should be visually strong.

---

# 18. RESPONSIVE DESIGN

Desktop is NOT the only design target.

The design MUST be intentionally adapted for:

* Desktop
* Tablet
* Mobile

Mobile must maintain:

* Typography hierarchy
* CTA visibility
* Image quality
* Navigation usability
* Animation usability

Do not simply shrink the desktop layout.

---

# 19. PERFORMANCE

Performance is part of the design.

Do NOT sacrifice:

* LCP
* CLS
* INP
* Mobile performance

for animation.

Use:

* Lazy loading
* Image optimization
* WebP/AVIF where appropriate
* Video compression
* Poster images
* Code splitting
* Lazy-loaded animation libraries
* Reduced motion support

Heavy visual sections must degrade gracefully.

---

# 20. ACCESSIBILITY

Must support:

* Keyboard navigation
* Focus states
* Sufficient contrast
* Alt text
* Semantic HTML
* Reduced motion preference
* Accessible buttons
* Accessible navigation

Animation MUST respect:

prefers-reduced-motion

---

# 21. TECHNOLOGY RULE

Preferred implementation:

React / Next.js
+
Tailwind CSS
+
GSAP
+
GSAP ScrollTrigger
+
Lenis where appropriate
+
HTML5 Video

Use Three.js/WebGL ONLY when the visual requirement genuinely needs 3D.

Do NOT introduce unnecessary technology.

---

# 22. ORIGINALITY RULE

Use transportation award-winning websites as references for:

* Visual hierarchy
* Composition
* Service storytelling
* Motion principles
* Photography direction
* Typography
* Information architecture

Do NOT reproduce:

* Logos
* Text
* Brand identity
* Exact sections
* Exact layouts
* Exact animation sequences
* Proprietary images
* Proprietary videos
* Exact visual assets

The final website must have its own brand identity.

---

# 23. QUALITY GATE

Before considering a section complete, evaluate:

1. Does it communicate something useful?
2. Does it support the transportation business?
3. Is the hierarchy immediately understandable?
4. Is the visual system consistent?
5. Does animation have a purpose?
6. Is the imagery relevant?
7. Does it work on mobile?
8. Does it maintain performance?
9. Is the CTA clear where appropriate?
10. Does it look like a transportation brand rather than a generic template?

If the answer is NO to any critical question, redesign the section.

---

# FINAL PRINCIPLE

The goal is NOT:

"Make a flashy Awwwards website."

The goal is:

"Create an original, premium transportation website using the visual discipline, storytelling, motion, typography, photography and interaction quality demonstrated by award-winning logistics and minimalist websites."

Business clarity always comes before visual effects.
